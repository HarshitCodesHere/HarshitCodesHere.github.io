# Bennett BuildLab — class prototype

A coursework prototype for a proposed student technology club and sample campus hackathon. It is fictional and is not an official Bennett University club or event.

**Project website:** [https://buildlab-class.me/](https://buildlab-class.me/)

The site presents student-focused pages for participation, sample schedule and rules, campus context, beginner resources, FAQs, and an archive policy. Dates, registration, venue booking, speakers, sponsors, awards, and results are not real or confirmed.
